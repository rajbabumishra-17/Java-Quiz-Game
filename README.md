# Java Quiz Game

A console-based Java Quiz Game developed as part of a Java Development Internship.

## Features
- 10 multiple-choice Java questions
- Object-oriented programming using classes and objects
- Score calculation and percentage display
- Replay functionality
- Input validation
- Score history saved to a text file
- Performance feedback based on quiz results

## Technologies Used
- Java
- VS Code
- Java File I/O

## How to Run

1. Install Java JDK.
2. Open the project folder in a terminal.
3. Compile the source files:

   `javac Question.java QuizGame.java`

4. Run the application:

   `java QuizGame`

## Project Structure

- `QuizGame.java` — Main application and quiz logic
- `Question.java` — Question model and answer checking
- `scores.txt` — Locally generated score history

## Concepts Demonstrated

Java OOP, arrays, loops, constructors, encapsulation, exception handling, input validation, and file handling.
